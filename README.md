One line of software error copy that tells the brutal truth about what went wrong — and makes you laugh. A payment that went through while its confirmation got lost, told straight, with a twist, and a concrete next step. Built for make.fun's "Say What Actually Broke" bounty: a single-line error message of at most 200 characters, funny on a single read, honest enough to ship in a real product's error dialog.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (one line, 134 characters, no trailing newline). Set `ENTRY_OUTPUT` to write it somewhere else, e.g. `ENTRY_OUTPUT=entry.txt python3 main.py`.
